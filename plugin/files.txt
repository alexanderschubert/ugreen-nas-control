# Every file the plugin installs: <source> <path under /usr/local/emhttp/plugins/ugreen-nas-control> <mode>
# source = path in the repo, or release:<name> for a binary built by `just go-build` (.build/bin/<name>).
# `release:<tool> <path> -> <target>` installs a symbolic link (target relative to the link's folder). The four tools are
# names of the one multicall binary backend/ugreen-nas (it runs as the tool its name says).
# Sources under .build/plugin (the JS bundles, the PNG icons) are written by `just web-build`
# (scripts/generated.ts). `bun plugin/tools/plg.ts pack` puts all of it into one archive at the install-relative paths
# and the .plg downloads that archive. `bun plugin/tools/plg.ts check` fails when a shipped file under web/plugin or
# plugin/event is missing here.
