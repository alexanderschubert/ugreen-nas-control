# UGREEN NAS Control

Fan curves, LED control and a live case view for your UGREEN NAS (DX, DXP and iDX series) on Unraid. A plugin, no kernel module.

## 🖥️ Demo

[Website](https://alexanderschubert.github.io/ugreen-nas-control/) | [Live demo](https://alexanderschubert.github.io/ugreen-nas-control/demo/?model=dxp6800-pro) | [Releases](https://github.com/alexanderschubert/ugreen-nas-control/releases/latest)

## 📦 Install

Unraid 7.2 or newer, x86 UGREEN models only.

- **Apps tab** (Community Applications): search "UGREEN NAS Control".
- Or **Plugins, Install Plugin** with `https://raw.githubusercontent.com/alexanderschubert/ugreen-nas-control/main/plugin/ugreen-nas-control.plg`.
- Beta channel (every merge to `dev`, not for production): see [docs/releasing.md](docs/releasing.md).

Then open **Settings, UGREEN NAS Control**.
